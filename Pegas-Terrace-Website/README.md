# Pegas Terrace & Restaurant

A standalone responsive restaurant website made with HTML, CSS, and vanilla JavaScript. It can be opened directly from `templates/index.html` or served from any static web host.

## Included

- Restaurant story, menu, experiences, private dining, photo gallery, visit details, and reservation sections.
- Interactive menu category tabs and responsive navigation.
- Reservation planner with browser-side required-field checks and a call-to-confirm summary.
- Entrance, hover, and scroll reveal animations with reduced-motion support.

The reservation planner does not send or store personal details. Customers call Pegas to confirm a table. Photos and typefaces load from hosted sources, so those need internet access.
